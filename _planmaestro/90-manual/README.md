# Manual

Documentación dirigida a **personas**, no a Claude Code.

Aquí va todo lo que alguien necesita saber para operar el proyecto sin leer el
código: cómo se edita el banco de preguntas, cómo se publica el sitio, qué se
configuró a mano en paneles externos.

Es el antídoto contra el conocimiento que vive solo en la cabeza del autor. Todo lo
que se configure fuera del repositorio y no quede escrito aquí, se pierde.

## Criterio de redacción

Están escritos para alguien que **no va a tocar el repositorio**. Si un documento no
puede seguirse sin saber programar, está mal escrito.
